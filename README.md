# 基于树莓派与深度学习的危险驾驶行为监测及预警系统

## 项目简介

本项目设计并实现了一套基于树莓派的危险驾驶行为监测及预警系统，利用摄像头实时采集驾驶员状态信息，通过计算机视觉与深度学习算法分析驾驶员面部特征、头部姿态以及手部动作，实现对疲劳驾驶、分心驾驶等危险行为的实时检测。

系统部署于 Raspberry Pi 嵌入式 Linux 平台，实现了图像采集、数据处理、行为识别、异常报警的完整流程，可作为智能驾驶辅助系统的原型方案，提高驾驶安全性。

# 系统功能

## 1. 疲劳驾驶检测

通过分析驾驶员眼部和嘴部状态，实现疲劳驾驶检测：

- 闭眼检测
- 长时间闭眼报警
- 打哈欠检测

核心算法：

- dlib 68点人脸关键点检测
- Eye Aspect Ratio（EAR）眼睛纵横比
- Mouth Aspect Ratio（MAR）嘴部纵横比

---

## 2. 分心驾驶检测

通过人体关键点检测驾驶员异常动作：

- 手部状态检测
- 手离方向盘检测
- 异常驾驶行为判断

核心技术：

- MediaPipe Hands
- 21点手部关键点模型

---

## 3. 头部姿态检测

通过人脸关键点与三维姿态估计，实现驾驶员头部状态分析：

- 点头检测
- 摇头检测
- 低头检测
- 视线偏移检测

核心技术：

- 人脸68关键点检测
- OpenCV SolvePnP三维姿态估计

---

## 4. 实时报警

当系统检测到危险驾驶行为时：

- 蜂鸣器进行声音提醒
- LCD显示当前异常状态
- 输出实时检测结果

# 核心算法介绍

## 1. 眼睛疲劳检测

利用 dlib 人脸68关键点模型定位眼睛区域。

通过 EAR（Eye Aspect Ratio）计算眼睛开合程度：

```
EAR = (||p2-p6|| + ||p3-p5||) / (2||p1-p4||)
```

当 EAR 小于设定阈值并持续一定时间，则判断驾驶员处于闭眼状态。


---

## 2. 打哈欠检测

通过嘴部关键点计算 MAR：

```
MAR = mouth_height / mouth_width
```

当 MAR 超过设定阈值时，判断驾驶员存在打哈欠行为。


---

## 3. 手部状态检测

使用 MediaPipe Hands 对手部进行关键点检测：

- 检测21个手部关键点
- 分析手部空间位置
- 判断驾驶员是否存在异常动作


---

## 4. 头部姿态估计

通过二维人脸关键点结合三维模型：

- 建立3D人脸参考模型
- 使用 SolvePnP 求解旋转矩阵
- 获取欧拉角（Pitch/Yaw/Roll）

实现：

- 点头
- 摇头
- 低头检测

# 项目难点与解决方案

## 1. 树莓派算力有限

问题：

树莓派 CPU 性能有限，复杂模型实时运行存在延迟。

解决：

- 优化图像分辨率
- 降低模型输入尺寸
- 减少不必要计算
- 使用轻量级视觉算法


## 2. 多模块实时协调

问题：

多个检测算法同时运行导致帧率下降。

解决：

- 模块化设计
- 优化检测频率
- 合理分配计算资源


## 3. 嵌入式环境部署

问题：

树莓派 Linux 环境下依赖库安装复杂。

解决：

- 配置 Python 虚拟环境
- 固定依赖版本
- 编写 requirements.txt
